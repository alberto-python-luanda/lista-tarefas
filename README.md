## 🚀 Sobre o projeto
Gerenciador de tarefas em Python com sistema completo:
- Adicionar tarefas com validação
- Listar tarefas com status
- Concluir tarefas (✅ FEITA / ⏳ Pendente)
- Tratamento de erros

## 🛠️ Funcionalidades
- `1` - Ver todas as tarefas
- `2` - Adicionar nova tarefa
- `3` - Marcar tarefa como concluída
- `4` - Sair
